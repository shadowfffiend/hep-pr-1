# Практическая работа 1: инженерное окружение ML-проекта

Проект классифицирует лабораторные показатели пациента как норма (0) или патология печени (1). Положительный класс объединяет гепатит C, фиброз и цирроз; результат модели не является медицинским диагнозом. Основа проекта — [курсовая работа](https://github.com/shadowfffiend/CW_Hepatitis_Streamlit).

## Структура

```text
app.py                 Streamlit-интерфейс
src/pipeline.py        Общая предобработка данных
src/train.py           Обучение XGBoost и оценка на тестовой выборке
src/predict.py         Пакетное предсказание из CSV
scripts/run_experiment.sh  Основной сценарий запуска эксперимента
models/pretrained/     Четыре исходных артефакта курсовой работы
data/raw/              Локальный CSV (не хранится в Git)
runs/                  Результаты запусков (не хранятся в Git)
notebooks/             Исходный ноутбук курсовой работы
```

## Требования и установка

- Linux, Bash, uv;
- Python 3.12, который `uv` может установить автоматически;
- доступ к Python-пакетам при первом `uv sync`;
- локальная копия `HepatitisCdata.csv` из [Hepatitis C Prediction Dataset](https://www.kaggle.com/datasets/fedesoriano/hepatitis-c-dataset).

Из корня репозитория:

```bash
uv sync --frozen
```

`pyproject.toml` задаёт прямые зависимости, `uv.lock` фиксирует точные версии. Каталог `.venv/` создаётся автоматически и не включается в Git. Набор данных тоже не публикуется в этом репозитории: скачайте архив набора данных, распакуйте CSV и поместите его в `data/raw/HepatitisCdata.csv` либо передайте любой другой путь через `--data`.

## Запуск эксперимента

```bash
bash scripts/run_experiment.sh --data data/raw/HepatitisCdata.csv --seed 42
```

Параметры скрипта:

| Параметр | Назначение |
| --- | --- |
| `--data PATH` | Обязательный путь к локальному CSV |
| `--seed INTEGER` | Для воспроизводимости разделения и обучения; по умолчанию `42` |
| `--out-dir PATH` | Корневой каталог результатов; по умолчанию `runs/` |
| `--help` | Справка |

Скрипт запускается с `set -euo pipefail`, проверяет параметры и создаёт новый каталог при каждом запуске. В каталоге лежат `run.log`, `params.json` (в том числе SHA-256 входного CSV), `metrics.json` и четыре `.joblib`-артефакта. Файлы метрик, параметров и модели создаёт `src/train.py`; Bash-сценарий запускает его и сохраняет вывод в `run.log`. Модель использует фиксированные параметры XGBoost.

Для предсказания подготовьте отдельный CSV с новыми пациентами и колонками `Age, Sex, ALB, ALP, ALT, AST, BIL, CHE, CHOL, CREA, GGT, PROT` (без `Category`). Например, сохраните его как `data/raw/new_patients.csv` и запустите:

```bash
uv run --frozen python -m src.predict --model-dir runs/ИМЯ_ЗАПУСКА --input data/raw/new_patients.csv --output runs/ИМЯ_ЗАПУСКА/predictions.csv
```

`Sex (пол)`  можно передать как `m`/`f` или `0`/`1`. Классы в файле результата: `0` — норма, `1` — патология печени.

## Streamlit-приложение

Приложение использует исходные артефакты курсовой работы из `models/pretrained/`.
Экспериментные модели, обученные Bash-сценарием, приложением не используются.

Запуск из корня проекта:

```bash
uv run --frozen streamlit run app.py
```

После запуска откройте адрес, который Streamlit покажет в терминале.
